Quem está construindo tudo isso

Uma apresentação honesta: onde eu estou, o que estou aprendendo e para onde estou indo.

Sou o Kauã, estudante de ensino médio integrado ao técnico em Desenvolvimento de Sistemas no SENAI. Passo metade da semana na escola e metade no SENAI aprendendo a transformar ideias em sites e apps — e é exatamente isso que eu gosto de fazer.

Este portfólio é meu registro de evolução: cada projeto aqui foi construído enquanto aprendia, do protótipo em papel até o JavaScript que deixa tudo interativo. Não tenho pressa de parecer pronto — tenho pressa de aprender de verdade.

Meu plano é simples: evoluir um dia de cada vez, absorvendo tudo o que o curso e a prática me ensinam, para estar preparado para qualquer caminho dentro da tecnologia — front-end, back-end ou o que ainda estiver por vir.
